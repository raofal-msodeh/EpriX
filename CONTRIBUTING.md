# 🤝 Contributing to EpriX

We welcome contributions from the community! By participating in this project, you agree to abide by the code of conduct.

## 🐛 Reporting Bugs

If you find a bug, please help us by submitting an issue to our [GitHub Repository](https://github.com/Alqudimi/EpriX). Before submitting, please check if the issue has already been reported.

When reporting a bug, please include:
*   A clear and concise description of the bug.
*   Steps to reproduce the behavior.
*   The expected behavior.
*   Screenshots or code snippets if applicable.
*   Your operating system and Python version.

## ✨ Suggesting Enhancements

We love new ideas! If you have a suggestion for an enhancement or a new feature:
1.  Check the existing issues to see if the suggestion has already been made.
2.  Open a new issue and clearly describe the feature or enhancement. Explain why it would be useful.

## 📝 Code Contributions

We follow a standard GitHub workflow for code contributions:

1.  **Fork** the repository on GitHub.
2.  **Clone** your forked repository locally.
3.  Create a new **branch** for your feature or fix: `git checkout -b feature/your-feature-name` or `git checkout -b bugfix/issue-number`.
4.  Make your changes and ensure your code adheres to the project's style guidelines (e.g., PEP 8 for Python).
5.  Write **tests** for your changes, if applicable.
6.  **Commit** your changes with a clear and descriptive commit message.
7.  **Push** your branch to your fork: `git push origin feature/your-feature-name`.
8.  Open a **Pull Request (PR)** against the `main` branch of the original repository.

### Commit Messages

Please follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification for your commit messages.

This project is governed by the Contributor Covenant Code of Conduct. By participating, you are expected to uphold this code.
