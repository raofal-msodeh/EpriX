# 🛡️ Security Policy

The EpriX project takes the security of its users and code seriously. We appreciate the efforts of security researchers and the community in helping us maintain a secure environment.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within EpriX, please report it immediately and responsibly.

**DO NOT** open a public GitHub issue.

Instead, please report the vulnerability directly to the developer via email:

*   **Email:** `eng7mi@gmail.com`

Please include the following details in your report:
*   A clear description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   The version of EpriX affected.
*   Any potential exploit code (if applicable, but please be cautious).

## ⏳ Our Commitment

The developer will acknowledge your report within **48 hours** and provide a detailed response indicating the next steps. We aim to confirm the vulnerability and release a fix as quickly as possible.

We will keep you informed of the progress toward a fix and will publicly acknowledge your responsible disclosure after the vulnerability has been patched and released.

## 🔑 Security Best Practices

As a user of EpriX, you are encouraged to:
*   Always use the latest stable version of the software.
*   Ensure your system's Python environment is up-to-date.
*   Use strong, unique passwords for encryption keys.
